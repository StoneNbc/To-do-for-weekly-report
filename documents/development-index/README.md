# 开发任务总索引

本目录是稳定的代码导航，不记录当前进度。开始任务时先读根目录 `AGENTS.md` 与 `documents/PROJECT_STATE.md`，再按下表只打开一个主模块；需要跨边界时遵循模块页的“修改联动”。

设计交接、人工验证与失败反馈的分工见[人机协作开发流程](../协作开发流程.md)，日常开发无需重复全文读取。

| 开发任务                                         | 主模块索引                               | 常见联动             |
| ------------------------------------------------ | ---------------------------------------- | -------------------- |
| 今日任务、历史补录、详情、完成、归档、周聚合     | [任务与文本数据](task-data.md)           | 共享契约、Renderer   |
| 项目目录、项目归属、统一改名及恢复             | [任务与文本数据](task-data.md)           | Renderer、共享契约、周报 |
| 便利贴页面、紧凑模式、任务交互、周记页面         | [Renderer 界面与状态](renderer-ui.md)    | 任务数据、共享契约   |
| 窗口、托盘、贴边、自动隐藏、多显示器、全屏 Space | [窗口与桌面集成](window-desktop.md)      | 设置、共享契约       |
| 颜色、透明度、置顶、贴边开关、诊断入口           | [设置与外观](settings-appearance.md)     | 窗口、共享契约       |
| 周报模板、生成、导出、远程 LLM、凭据与网络策略   | [周报与远程 LLM](report-llm.md)          | 任务数据、共享契约   |
| IPC、Preload、共享类型、启动、监听、调度与退出   | [共享契约与运行时](contracts-runtime.md) | 所有业务模块         |
| 版本、构建、安装包、GitHub Actions 与发布        | [构建与发布](build-release.md)           | 运行时资源、用户文档 |

选择原则：按“用户要改变的行为”选择主模块，而不是按报错文件选择；例如贴边颜色从设置页触发，但行为落在窗口状态机，应先读“设置与外观”，再按联动读“窗口与桌面集成”。
